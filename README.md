# UpahJe.my

Malaysia-first marketplace for hiring people for practical, local work.

Production preview: https://upahje-my.vercel.app

## Stack

Next.js 14, TypeScript, React, Tailwind CSS, Supabase, Prisma/PostgreSQL, Billplz, and Vercel.

## Main features

- Browse jobs, categories, talent profiles, and portfolios
- Employer job posting and talent applications
- Role-aware onboarding and dashboards
- MyKad/KYC upload and admin review
- Payment and escrow API primitives
- Reviews and early AI task workflow surfaces

## Quick start

```bash
npm install
npm run db:generate
npm run dev
```

Production build:

```bash
npm run build
```
