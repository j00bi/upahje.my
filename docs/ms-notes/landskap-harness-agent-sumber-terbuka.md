## Register checks applied

- `anda` for the reader; `kami` where the page describes its own experience.
- No particles, no `kalau`, no `macam mana`; `yang mana` avoided entirely.
- `ialah` in definitional sentences only.
- No em dashes. No host paths, usernames or session identifiers; the payload path is described, not printed.
