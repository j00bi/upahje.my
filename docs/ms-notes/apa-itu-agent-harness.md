## Sentences written fresh rather than translated

1. `Bacalah sebagai tiga bahagian` opens the path explanation; the English "Read that as three parts" would have become `Baca itu sebagai` which is stilted.
2. `Itu wajar diketahui sebelum anda menampal kontrak pelanggan` renders "worth knowing before you paste a client contract" as a `wajar` clause instead of a calque.
3. `bukan sesuatu yang halaman ini boleh dakwa bagi pihak anda` replaces "not something this page can claim for yours", which as a literal `bukan sesuatu yang halaman ini boleh dakwa untuk anda` reads translated.
4. `saya tidak akan menekanya` closes the last FAQ. English "guess at it" became `meneka`, not `membuat tekaan`, which is the noun-heavy version.
5. `tetingkap sembang` for chat window; `tetingkap` is the BM word for window in software, not `jendela`, which is the Indonesian and physical-window sense.

## For the native reader

- `dinyahmampat` is correct but stiff; `dibuka` or `didekompres` would read easier at some cost in precision.
