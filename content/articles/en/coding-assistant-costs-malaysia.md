# What a coding assistant costs a Malaysian SME

One paid coding seat costs a Malaysian small business between RM41 and RM412 a month. The lower figure is GitHub Copilot Pro, the higher is Claude Max or Copilot Max, both priced in US dollars and converted here. Most SMEs should not buy a seat yet: the free tiers cover occasional use, and a paid tier only pays for itself when someone on the team writes code most working days.

## Four bundles carry a coding surface

Claude Code is included in Claude Pro and every tier above it. Codex is included in ChatGPT Plus and above. GitHub Copilot lists Claude Code and Codex as third-party agents on its paid plans. Google's Gemini plans feed Antigravity, and the AI Pro tier is where its entry rate limits start.

That matters because the cheapest seat that drives a coding agent is not the cheapest seat overall. Copilot Pro at RM41.19 is the cheapest paid entry to a coding agent on this list; Google AI Plus at RM23.99 is cheaper but its page describes a general assistant plan, not an agent with repository access.

## The free tiers are enough for some work

Copilot Free gives 2,000 completions a month. Claude Free gives limited usage every five hours and every week, in the vendor's own wording. Gemini's free tier is MYR 0 with automatic model selection, and ChatGPT Free exists at zero with limits on most features.

If the job is one small script a month, or a formula that will not work in a spreadsheet, a free tier will do it and a paid seat is a hobby budget rather than a business cost.

## The seat price is not the API price

A subscription and an API key are different purchases, and the coding-agent seats do not include one. Claude Pro and ChatGPT Plus list no API credits. Claude Max includes USD 100 a month of API credits, the same figure as its price, and ChatGPT Pro includes credits up to its tier price. Copilot's monthly credits are GitHub AI Credits for its own features, not an API.

The consequence is practical: if your team runs an agent in a pipeline or a nightly job, the seat does not cover it and you are buying tokens on a meter as well. [What RM100 a month buys you in AI](https://upahje.my/en/articles/rm100-budget) works that meter in ringgit.

## Whether to pay at all

My opinion, stated once: not until someone writes code most working days. Below that volume, a free tier plus pay-as-you-go API credits costs less than any seat, and you keep the choice of model instead of buying a bundle.

The exception is a business whose product is software. There, one seat is a rounding error against the cost of a bad week, and the annual Claude Pro rate, RM70.01 against RM82.37 monthly, is the same seat sold cheaper. Copilot prices per user, so a team of three pays three times.

## What is not published

No vendor publishes the hours its assistant saves, and no Malaysian study of that exists that could be cited here. Copilot Business and Enterprise prices are not on the plans page read, which sells Free, Pro, Pro+ and Max only. Cursor and Windsurf were not read for this article, so they are absent rather than estimated.

The one honest comparison a reader can make is between published prices, which is what the table above does.

## What to do this week

1. Count last month's coding work, in tasks rather than hours.
2. Run one real task, not a demo, in a free tier.
3. Ask whether anyone would use a paid seat four days a week.
4. If yes, price the annual option against the monthly one, and check whether the vendor bills per user.
5. Keep the API key separate from the seat, because the seat does not include one.

## FAQ

### Is a Claude Pro subscription the same as an API key?

No. Claude Pro at USD 20, or RM82.37 here, includes the app and Claude Code, and lists no API credits. An agent you run yourself needs its own key.

### Which is the cheapest seat that drives a coding agent?

GitHub Copilot Pro at USD 10, or RM41.19 a month. Claude Pro at RM82.37 is the next step up, and both are per user.

### Do I have to pay in US dollars?

Claude and Copilot publish USD prices, so the ringgit figure moves with the exchange rate. ChatGPT and Gemini publish MYR prices for Malaysia, which do not move with it.

### Can one seat cover a team?

Copilot prices per user. The consumer plans read for this article publish a single-user price and no team price, so a shared login is outside what the pages say.
